## 2024 NTHU COM 621000 Advanced Topics in Speech Applications 進階語音訊號處理 Lab 2  
This is a folder to record Lab2 of Advanced Topics in Speech Applications, Lab2 mainly focus on Speech Enhancement (語音增強).  
The main task of Lab2 is to use the diffusion-based generative model (SGMSE) to implement Speech Enhancement and Dereverberation.  

#### Dataset Information  
| Noise Dataset | Training set | Testing set |
| ------------- | ------------ | ----------- |
| ESC-50 | VCTK Corpus | IEMOCAP Session 1 |

#### Methods  
To utilize the SGMSE model, the training data must contain both clean and noisy data.  
Noisy datat is generated by mixing noise from ESC-50 to clean data with certain signal-noise ratio (SNR)  
The training data are used to finetue the SGMSE model with the pretrained checkpoint train_wsj0_2cta4cov_epoch=159.ckpt.
