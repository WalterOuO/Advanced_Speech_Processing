## 2024 NTHU COM 621000 Advanced Topics in Speech Applications 進階語音訊號處理 Lab 1  
This is a folder to record Lab1 of Advanced Topics in Speech Applications, Lab1 mainly focus on Automatic Speech Reconition(ASR).  
The main task of Lab1 is to finetune Whisper model with VCTK dataset, and the testing set is IEMOCAP Session1.  
The testing set from IEMOCAP [Session 1]([url](https://drive.google.com/file/d/1mwYpQowUbmrCnDC5zkzABqcuTgFepu6w/view?usp=sharing)) could be obtained from this link.
